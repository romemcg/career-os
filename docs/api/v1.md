# API v1 (Milestone 1)

All workspace endpoints require the session cookie. Mutating requests must be same-origin.

Success: `{ "data": ..., "meta": { "requestId": "uuid", ... } }`
Error: `{ "error": { "code": "VALIDATION_ERROR", "message": "...", "details": [{ "path": "content.startDate", "message": "..." }] } }`

| Code                                           | HTTP |
| ---------------------------------------------- | ---- |
| `VALIDATION_ERROR`                             | 400  |
| `UNAUTHENTICATED`                              | 401  |
| `FORBIDDEN`                                    | 403  |
| `NOT_FOUND`                                    | 404  |
| `CONFLICT`, `REVISION_CONFLICT`                | 409  |
| `PAYLOAD_TOO_LARGE`                            | 413  |
| `UNSUPPORTED_MEDIA_TYPE`                       | 415  |
| `INVALID_TRANSITION`, `IDEMPOTENCY_KEY_REUSED` | 422  |
| `RATE_LIMITED`                                 | 429  |
| `INTERNAL_ERROR`                               | 500  |

## Endpoints

| Method | Path                                 | Notes                                                                                                                                                                    |
| ------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| GET    | `/api/health`                        | Public readiness probe; component status only                                                                                                                            |
| POST   | `/api/v1/auth/login`                 | `{ email, password }`; sets cookie                                                                                                                                       |
| POST   | `/api/v1/auth/logout`                | Revokes the session                                                                                                                                                      |
| GET    | `/api/v1/auth/session`               | 200 if signed in                                                                                                                                                         |
| GET    | `/api/v1/profile`                    |                                                                                                                                                                          |
| PATCH  | `/api/v1/profile`                    | `{ revision, headline?, summary?, location? }`; 409 if stale                                                                                                             |
| GET    | `/api/v1/career-facts`               | `?status=&type=&q=&cursor=&limit=` (default 20, max 100); `meta.nextCursor`                                                                                              |
| POST   | `/api/v1/career-facts`               | `{ factType, content, sourceId?, supersedesFactId? }`; always created `unverified`; supports `Idempotency-Key`                                                           |
| GET    | `/api/v1/career-facts/:id`           |                                                                                                                                                                          |
| PATCH  | `/api/v1/career-facts/:id`           | `{ action: "edit", revision, content?, sourceId?, note? }`, `{ action: "verify", revision }`, `{ action: "reject", revision, reason }`, `{ action: "reopen", revision }` |
| GET    | `/api/v1/career-facts/:id/revisions` | Newest first                                                                                                                                                             |
| GET    | `/api/v1/fact-sources`               |                                                                                                                                                                          |
| POST   | `/api/v1/fact-sources`               | `{ sourceType, title, documentId?, reference?, notes? }`; supports `Idempotency-Key`                                                                                     |
| GET    | `/api/v1/documents`                  |                                                                                                                                                                          |
| POST   | `/api/v1/documents/upload`           | multipart `file`; 201 new, 200 with `meta.duplicate` for identical content                                                                                               |
| GET    | `/api/v1/documents/:id`              | Streams original as attachment after checksum verification                                                                                                               |
| DELETE | `/api/v1/documents/:id?confirm=true` | 409 if cited by a source                                                                                                                                                 |
| GET    | `/api/v1/activity`                   | Recent audit entries (no metadata)                                                                                                                                       |

## Fact content by type

| Type            | Required                       | Optional                                                                    |
| --------------- | ------------------------------ | --------------------------------------------------------------------------- |
| `employment`    | organization, title, startDate | location, endDate (null = current), employmentType, description             |
| `education`     | institution, qualification     | fieldOfStudy, startDate, endDate, grade                                     |
| `certification` | name, issuer                   | issuedDate, expiryDate, credentialId                                        |
| `skill`         | name                           | category, proficiency, yearsOfExperience                                    |
| `achievement`   | statement                      | context, organization, metric `{ value, unit?, description? }` (text), date |
| `project`       | name, description              | organization, role, startDate, endDate, technologies[]                      |

Dates are `YYYY`, `YYYY-MM` or `YYYY-MM-DD`. Unknown keys are dropped.
